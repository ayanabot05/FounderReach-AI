# AYANA manual qualified-inquiry rubric (pilot v1)

Freeze this rubric before the 28-day pilot. A **signup** is a successfully created AYANA account. A **qualified inquiry** is a separate, voluntary inbound message or form submission that a human reviews; neither a signup nor a CTA click automatically qualifies.

## Label one inquiry

Count as **qualified** only when all are supported by the inquiry itself or a consented follow-up:

1. The sender is a family member or caregiver with a parent or older relative in India, or is arranging that person's care from elsewhere.
2. They describe a current check-in, medicine reminder, missed reply, or family safety coordination need in their own words.
3. They ask about using AYANA, request a demo, pricing, setup, or a specific next step.
4. The message is voluntary and contact is permitted by the channel's rules; it is not the result of unsolicited outreach.

Label **unqualified** when any required element is absent, the sender is a vendor/job seeker/researcher, the record is spam, or the concern is an emergency or medical advice request that AYANA cannot address. Label **uncertain** when the evidence is ambiguous; do not count it as qualified until a human resolves it.

Deduplicate by the same person and need within 28 days. Preserve only the minimum necessary private contact details in the existing AYANA system, never in public reports. In the pilot sheet record a pseudonymous inquiry ID, received date, channel, tagged visit if available, the four criterion decisions, reviewer, outcome, and a short redacted evidence note. A second reviewer resolves disputed labels before the final count.

Report **signups**, **qualified inquiries**, and **uncertain inquiries** as separate columns. An inquiry can also become a signup, but each metric keeps its own definition. No inquiry event is currently installed on AYANA, so the reported count is `N/A` until an existing consented contact channel and manual log are verified. Never substitute signup count for inquiry count or claim that zero observed means zero inquiries.
