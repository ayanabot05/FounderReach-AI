## AYANA brand SEO audit and local patch

The existing homepage source had one canonical pointing to `https://www.ayanabott.com/`, an indexable robots directive generated by the build, a service H1, a sitemap entry, Organization and WebSite JSON-LD, and social metadata. `robots.txt` allows crawling. The About page already named founder Guna Kanumuri and linked the official domain. The missing connection was the product name **AYANA BOT** in the homepage title, description, rendered copy, About copy, and WebSite alternate name. The public HTML template and route metadata also used different descriptions before build, so both now use the same wording. No guide page was changed or re-audited.

Local optimized build succeeded. `npm run test:brand-seo` passed against generated initial HTML for homepage and About: one title, description, canonical, Open Graph title, social title, and valid parseable Organization/WebSite schema per page; indexability, sitemap, and visible identity also passed. ### Search Console verification after an approved deployment

1. In the verified domain property, use **URL Inspection** for `https://www.ayanabott.com/` and `/about`. Check fetched HTML, indexing status, Google-selected canonical, and live test. Request recrawl only after the approved patch is deployed.
2. In **Performance → Search results**, use Web search and compare a 28-day pre-deployment window with the following 28 days. Filter queries separately for `AYANA`, `AYANA BOT`, `AYANA BOTT`, `ayanabott`, and `AYANA WhatsApp parents`; record impressions, clicks, CTR, and average position. Filter the page to the homepage when assessing branded homepage visibility. Keep country and device context consistent.
3. Export the query/page tables and annotate the deployment date. Low-volume or anonymized query rows may be absent, and search results vary by user and location; do not treat a manual search as the measurement baseline.

These steps follow [Google's site-name guidance](https://developers.google.com/search/docs/appearance/site-names), [Search Console Performance filters](https://support.google.com/webmasters/answer/17011165?hl=en), and [URL Inspection](https://support.google.com/webmasters/answer/9012289/).
